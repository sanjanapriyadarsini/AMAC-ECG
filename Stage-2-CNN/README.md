# AMAC-ECG — Stage 2: CNN Experiments

This folder contains the Stage 2B CNN implementation for the AMAC-ECG project.

## Contents
- `AMAC_ECG_Stage2B_CNN.ipynb` — Google Colab notebook containing the CNN training workflow, code and execution outputs.

## Experiment Overview
- Dataset: MIT-BIH Arrhythmia Database (DS1)
- Model: Convolutional Neural Network (CNN)
- Evaluation: 5-fold patient-grouped cross-validation
- Focus: Minority-class arrhythmia detection and RR feature contribution

See the main repository's `stage2.md` for the detailed methodology and results.

## Note
The dataset and large prediction artifacts are not included in this folder.
